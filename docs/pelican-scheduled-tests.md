# 鹈鹕定时测试

账号管理 → 账号“更多” → 鹈鹕测智 → 定时测试。

直接复用现有 `ScheduledTestsPanel`、计划 CRUD 接口、数据库和后台调度器，支持添加多个计划、编辑、启停、删除和查看结果。每个计划使用标准 5 字段 Cron（默认 `*/30 * * * *`），沿用模型、最大结果数、启用和自动恢复选项；鹈鹕计划另保存题目、思考强度和并行数。关闭网页后仍由服务端执行，不设默认自动停止时间。

- 最大结果数默认 100，可设 1–200，按每份输出计数；每轮 1–8 份并行输出。
- 每次生成后按最大结果数裁剪历史，超过 7 天的记录每分钟清理（每批最多 1000 条），暂停后仍清理。单份文本最多 2 MiB，超限保留失败信息、不保存正文；SSE 捕获最多 4 MiB。数据库删除由 PostgreSQL 常规 autovacuum 回收复用空间，并不保证数据文件立即缩小。
- 每份结果记录当时的配置、耗时、正文和错误。列表只读取摘要，点击后加载 HTML，继续使用隔离 iframe 和 CSP，可下载，不自动评分。
- 自动恢复沿用原选项：启用后，一轮中有成功输出时调用现有账号状态恢复流程；默认关闭。
- 多个鹈鹕计划使用账号级数据库锁和计划租约，防止同一账号的计划同时开始；每轮最多执行 10 分钟，进程崩溃后的租约 15 分钟过期。错过的轮次不批量补跑，暂停后已经开始的一轮会完成。
- 原连接测试继续使用相同组件和原行为，鹈鹕入口只列出该账号的鹈鹕计划。手动测试的本地历史保持原入口。

数据库迁移 `243_pelican_scheduled_tests.sql` 仅为现有计划增加可空配置和租约，为结果增加配置快照；原连接测试的配置为 NULL。运行新功能后回滚到旧调度器前，应先暂停鹈鹕计划。

验证使用本地 mock 数据及临时 PostgreSQL/Redis 容器，不创建生产计划或调用真实模型。

# Infinite Canvas 与 Sub2API 集成

## 权限与配置

- 界面名称统一为「无限画布」；启用后入口显示在左侧导航最后，普通用户和管理员均排在自定义菜单之后。
- Sub2API 管理员在「设置 → 功能开关 → 无限画布」启用并填写画布 URL。配置保存在后端数据库，对所有用户生效，默认关闭；旧浏览器开关不会自动发布到全站，需要管理员重新保存一次。
- 嵌入白名单自动跟随画布设置：启用时将画布 URL 的 HTTP/HTTPS origin（协议、域名及端口，不含路径和查询参数）加入 Sub2API 的 CSP frame-src。保存新地址后替换旧授权，关闭后移除画布授权；其他功能仍使用同一域名时保留其授权。无需手工修改安全响应头或重启服务，保存后刷新 Sub2API 页面即可生效。
- 登录用户读取 GET /api/v1/canvas/settings；仅管理员可写 PUT /api/v1/admin/settings/canvas，沿用现有管理员认证中间件。
- 首次进入 /canvas 选择自己的有效 API Key，记住的是该用户的 key ID；不会自动创建或选定其他用户的密钥。
- 画布设置页分别显示「API 站点（管理员统一设置）」与「我的密钥（当前账号）」，可随时打开「切换密钥」。顶部不显示连接信息。每次打开会刷新可用密钥；确认时再次由后端校验，通过后保存选择并重新连接。取消或验证失败保留当前画布；切换前请结束生成和 Agent 对话，已提交的上游任务不保证取消。
- 管理员在「设置 → 功能开关 → 无限画布」配置「画布 API 站点（Base URL）」。须填写接受本站 API Key 的网关根地址，例如 https://api.example.com，不是画布 URL 或 /v1/responses 等单个接口地址。留空时继承全站 API 地址；两者均为空时使用当前 API 服务地址。跨域地址仍需正确配置网关 CORS。
- API 站点设置保存在服务器，仅管理员可写；用户端只读显示站点，密钥始终由用户选择自己的。会话中的 baseUrl 由后端配置决定，不接受画布消息指定地址。设置页显示最近一次握手实际使用的地址；管理员改地址后刷新画布或重新握手生效。该地址是画布访问的网关，不展示网关背后的上游供应商凭据。
- GET /api/v1/canvas/session/:id 在后端校验全站开关、登录身份、当前数据库角色、密钥归属、分组分配、状态、有效期和配额。会话响应禁止缓存，不向 iframe 传递面板 JWT。网关对每次生成继续执行分组权限、额度、IP 等授权与计费。
- 普通用户使用宿主提供的只读渠道，可修改个人创作偏好、WebDAV 和本地数据；配置导入、存储更新、提示词源修改仍有角色限制。普通用户可用「Agent 对话」，本地 Codex 入口仅管理员可用。
- 管理员拥有画布自身的渠道、模型脚本、本地代理、提示词来源、偏好、WebDAV、本地数据和 Agent 能力。宿主渠道的站点、密钥、协议及可用模型名单来自平台；管理员可编辑该渠道的模型用途、调用脚本和生成方式，也可另加自己的渠道；这些配置属于管理员个人，不会发布给其他用户。画布内不增加平台管理面板。
- 宿主渠道与调用密钥只在内存合并，不写入配置存储或配置导出。管理员自建渠道密钥、WebDAV 凭据仍按独立画布设计保存在浏览器，并可能包含在完整配置导出中。
- 画布、素材、记录等继续按宿主 origin + 用户 ID 区分本地存储，没有云同步或针对浏览器持有者的加密隔离。前端角色控制不是后端授权替代品；独立模式仍可使用完整本地功能。

## Agent 对话模式

- 画布右上角打开 Agent，默认进入「Agent 对话」；管理员仍可切换「本地 Codex」。新模式由浏览器直连已配置渠道，无需启动 canvas-agent。
- 选择支持 `/v1/responses`、流式返回和 function calling 的 OpenAI 兼容对话模型；需要看图时模型还须支持图像输入。图片模型单独选择，复用现有图片生成、参考图编辑、异步任务和计费链路。普通用户仅能使用宿主密钥及分组允许的模型。
- 支持多轮对话、画布文本/图片引用、读取画布、添加文本、生成图片、参考图编辑及移动节点。写入操作默认展示审核卡片，参数可展开查看；用户可在输入区选择「手动审核 / 自动审核」，自动审核直接批准写操作（包括可能计费的生图），只在当前页面的当前会话内生效，切换/新建会话、切换项目、刷新或身份失效恢复手动，运行中不能切换；图片生成一项调用一张，依赖图片在前一张完成后继续。失败不自动重试，停止后已提交的上游生成不保证取消或免计费。
- 对话按宿主 origin + 用户 ID + 画布项目保存到 IndexedDB，可新建及切换历史；不保存宿主密钥。对话包含发送给模型的参考图，暂无 WebDAV 对话同步或画布导出携带对话。页面刷新不会自动续跑未完成的工具。
- 对话与工具消息按 threadId / turnId / itemId 归属；工具结果完整回传给模型。数据流未完成、重复调用 ID、账号失效、切换画布会阻止继续执行。未知存储版本或损坏数据拒绝覆盖。
- 实现参考 gpt_image_playground v0.8.0 / main 提交 `1e9d5af60aadd9117a835cc2da43908b8e3370dd` 的独立对话/生图渠道思路，自行适配本项目；未移植其完整界面、内置 image_generation、网页搜索、蒙版编辑或并行批量生成。
- 针对性测试：`cd web && node --test tests/browser-agent.test.cjs tests/canvas-permissions.test.cjs`；会话边界测试：`bun test tests/sub2api-integration.test.ts`。Agent 与权限共 20 项模拟测试通过，另有 4 项会话边界测试；独立预览已验证侧栏浅深主题、390px 窄屏、模型/会话切换及手动/自动审核。真实网关和生图费用需使用可用渠道验收。

## 会话生命周期

- 图片与文本密钥分别按用户 ID 记住选择；未单独选择时沿用默认密钥。握手对默认、图片、文本每把不同密钥分别调用现有会话接口校验，不能用默认密钥的权限代替其他密钥校验。文本/图片模型列表和实际请求分别使用对应密钥，视频/音频仍使用默认密钥；无权限模型不自动换密钥调用。设置页只显示对应密钥名称和 ID，宿主凭据不进入持久化配置或导出。
- 确认任意用途密钥切换后，宿主重建 iframe 并传入新会话；取消或验证失败保留原选择。点击「重新连接」由画布向精确可信宿主发送 reconnect 消息，再由宿主重建 iframe。画布内部导航或刷新可保留自身来源的 referrer，但仍必须通过精确父窗口、可信 origin、协议与请求 ID 的完整握手；不能绕过宿主认证。
- 回到窗口或标签页会重新校验；用户名、密钥名称和凭据更新不会自动重载整页。主题、语言变化不改变 iframe URL。
- 深浅主题通过可信父窗口消息实时同步至画布，初次握手和 iframe 加载时补发；主题切换入口及圆形扩散动画统一放在宿主顶部，减少动态效果或浏览器不支持时直接切换。需要同时更新宿主与 Canvas 前端；真实嵌入动画和切换时对话保持仍待验收。
- 注销、身份或角色变化时停止旧会话；验证失败显示重新连接提示，不反复自动刷新。账号切换由宿主重建 iframe，避免混用用户存储。正在执行的请求不承诺自动撤销，后续网关请求仍受后端授权限制。
- 关闭全站开关立即阻止新会话；已打开页面在下次回到前台/会话校验时发现关闭。此功能未增加实时推送，也不会撤销用于其他客户端的 API Key。

## 部署

1. 更新并重启 Sub2API 后端，同时更新两个前端；Canvas 可独立部署。
2. 在 Sub2API 功能开关填写浏览器可访问的画布 URL。本地示例为 http://127.0.0.1:3010/；生产必须填写用户浏览器能访问的地址。
3. Canvas 的 web/.env.local 或构建环境设置 VITE_SUB2API_ORIGIN=http://127.0.0.1:3000（生产替换为精确 HTTPS origin），重新启动开发服务或重新构建。生产托管模式必须有可信来源配置；URL 中的 host_origin 不能覆盖它。localhost 与 127.0.0.1 不等价。
4. Sub2API 的 API Base URL 必须可从画布浏览器访问；跨域网关须允许画布 origin、Authorization 和 OPTIONS。Sub2API CSP frame-src 允许画布，Canvas CSP frame-ancestors 仅允许宿主，不能以 X-Frame-Options: DENY 阻挡嵌入。
5. 直接访问画布可继续独立使用；integration=sub2api 的嵌入页面必须握手。生产静态资源、HTTPS、CSP、CORS 和真实生成仍需部署环境验收。

## 验证

### 画布设置读取失败

- 如果 `GET /api/v1/canvas/settings` 返回 404，检查运行中的后端是否包含画布路由。Vite 会热更新前端，但 `go run` 不会自动重编译后端；更新源码后必须停止旧后端，再在 `backend` 目录执行 `bash scripts/run-local.sh`。本地默认监听 `127.0.0.1:8083`，与前端默认代理一致。
- 使用 `curl -i http://127.0.0.1:3000/api/v1/canvas/settings` 检查前端代理：未携带登录凭据时返回 401 表示请求已到达认证路由；登录后应返回 200 和 `{ enabled, url }` 配置。不要通过关闭认证或写死前端默认值绕过接口错误。
- 后端更新完成后刷新管理设置页；页面不会自动重新读取之前失败的画布设置。
